# Engineering Directive ED-0021
**Project:** CYBERMIND Platform
**Volume:** 21
**Domain:** UEBA
**Status:** Architecture Design
**Architecture Freeze:** v1.1

## 1. Mission
Detect behavioural anomalies.

## 2. Vision
Establish a highly resilient, enterprise-grade bounded context for UEBA that adheres to Zero Trust principles.

## 3. Purpose
To cleanly decouple UEBA capabilities from adjacent platforms and prevent monolithic anti-patterns.

## 4. Scope
Encompasses the complete lifecycle and orchestration of UEBA objects without duplicating core services.

## 5. Responsibilities
Manage domain logic, state transitions, and API contracts for UEBA.

## 6. Owns
- Behaviour baselines
- Behaviour profiles
- Insider risk
- Entity risk

## 7. Never Owns
- Alerts
- Telemetry
- Incidents

## 8. Domain Model
- `UEBAAggregate`
- `UEBAPolicy`
- `UEBARecord`

## 9. Aggregates
Data mutations within UEBA are strictly transacted across aggregate roots to ensure consistency.

## 10. Value Objects
Immutably models properties (e.g., timestamps, IDs, status codes) used by the domain.

## 11. Domain Events Published
- BehaviourAnomalyDetected
- EntityRiskScoreUpdated

## 12. Domain Events Consumed
- IdentityEvent
- Asset PlatformEvent

## 13. Commands
- `CreateUEBA`
- `UpdateUEBA`
- `DeleteUEBA`

## 14. Queries
- `GetUEBAById`
- `ListUEBAs`

## 15. Lifecycle
Baseline -> Monitor -> Detect Deviation -> Score Risk

## 16. AI Integration
AI models assist with UEBA insights via prompt-based recommendations, retaining human-in-the-loop authority.

## 17. Knowledge Graph Integration
UEBA maps relationships into the global ontology to maintain blast-radius and semantic correlation.

## 18. Search Integration
UEBA indexes read-optimized metadata into the Search service for global platform discovery.

## 19. Workflow Integration
Workflow Platform is responsible for orchestration. This domain must never execute long-running workflows directly.

## 20. Identity Integration
Strict RBAC and ABAC policies govern all API and command execution via the Identity Platform.

## 21. Event Bus Integration
Asynchronous message passing via Kafka ensures decoupled state synchronization.

## 22. Storage Strategy
Domain state is persisted in isolated datastores; read models are eventually consistent.

## 23. Public APIs
- Query API
- Command API
- Administration API
- Metrics API
- Search API
- Export API

## 27. Governance
Data retention, schema changes, and deployments are strictly governed by CI/CD pipelines and ADRs.

- DDD

- AI Ready

- Observable

## 29. Constitutional Principle
> Behavioural anomalies indicate risk variation, not definitive detection.

## 30. Future Extensions
Integration into broader CYBERMIND ecosystem workflows as defined in Version 2 Roadmap.
